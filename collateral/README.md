# JALLITS profile collateral

`jallits-profile-kit.zip` contains upload-ready GitHub organization and LinkedIn
company profile artwork, editable SVG sources, profile copy, and instructions.

The kit includes square logos, a LinkedIn cover in standard and high-resolution
sizes, a light logo alternative, the existing website SVG logos, an optional
AI-generated background, and a GitHub organization profile README.

Profile copy reflects the website's service positioning. Review platform crops
and company details before publishing. The artwork uses uppercase JALLITS and
the website's midnight, mint, and violet palette.
